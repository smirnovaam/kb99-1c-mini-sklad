# Мини-Склад (kb99-1c-mini-sklad)

Учебный проект по курсу "1С Старт с нуля". 

## Состав конфигурации:
* Справочники: Товары, Контрагенты.
* Документы: Поступление товаров, Реализация товаров.

## Как открыть:
1. Создайте пустую информационную базу в 1С.
2. Откройте Конфигуратор.
3. Выберите "Конфигурация" -> "Загрузить конфигурацию из файлов".
4. Укажите путь к корню этого репозитория.
5. Обновите базу данных и запустите Предприятие.
